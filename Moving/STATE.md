### ✅ งานชิ้นแรกของ Moving — ปรับคำเขียนบล็อก "Auditor Voices" (เสร็จแล้ว)

ก่อนหน้านี้ Moving ยืนรอคำสั่งมาตั้งแต่สร้างตัวตน 25 ส.ค. 2569 **นี่คืองานแรกที่ได้รับจริง**

บรีฟเต็มอยู่ที่ [`TASK-AUDITOR-VOICES.md`](TASK-AUDITOR-VOICES.md)

**ที่ทำ:**
- แก้ตัวแปร `AW_VOICE` ใน `Noting/design/build-mockup.py` (การ์ดผู้ตรวจ 4 ใบ บนหน้า `/awards`) ด้วยสคริปต์ [`apply_auditor_voices.py`](apply_auditor_voices.py)
- **ใช้ถ้อยคำที่ Boss เขียนมาให้ตรง ๆ ทุกตัวอักษร ไม่แต่งเพิ่ม ไม่ตีความใหม่** — ตรวจเทียบคำต่อคำในเบราว์เซอร์แล้วตรงกับที่ Boss ส่งมาทั้ง 4 ประโยค
- **เพิ่มฟิลด์ใหม่ `d:` (หมวดถนัด)** ที่โครงสร้างเดิมไม่มี — โครงสร้างโบรกเกอร์ / ต้นทุนการเทรด / กฎหมายการเงิน / บริการลูกค้า พร้อมเพิ่ม CSS `.aw-vc .dm` เป็นป้ายสีทองใต้ชื่อ (ใช้ไล่สีทองชุดเดียวกับ avatar เพื่อให้เข้าระบบสีเดิม ไม่ตั้งสีใหม่)
- ชื่อเปลี่ยน 2 คนตามที่ Boss ระบุ: นภัส → **นที** เจริญวงศ์ · กันติมา → **กันตินา** ศรีสุวรรณ
- แท็กเปลี่ยนจากไทยเป็นอังกฤษทั้งหมด (Regulation, Execution Test, Client Agreement, Withdrawal Test ฯลฯ)

**ข้อสังเกตเชิงคุณภาพที่อยากบันทึกไว้:** คำพูดชุดเดิมมี**ตัวเลขสมมติจำนวนมาก** (ทดสอบ 5,000 ไม้/เดือน · ถอน 12 ครั้ง · ใบอนุญาต 4 เขต) ซึ่งไม่เคยมีการตรวจจริงรองรับเลย — เวอร์ชันใหม่ของ Boss **ตัดตัวเลขออกหมด เหลือเป็นหลักคิดล้วน ๆ** ถือว่าดีขึ้นมากในแง่ความถูกต้อง ลดความเสี่ยงการกล่าวอ้างเกินจริงลงไปอีกชั้น

**⚠️ สิ่งที่คงไว้โดยตั้งใจ:** บรรทัดหมายเหตุใต้บล็อก (`aw-hxvn`) ที่ระบุว่า *"ชื่อผู้ตรวจและข้อความทั้งหมดในส่วนนี้ตั้งขึ้นเพื่องานออกแบบ ยังไม่ใช่คำให้สัมภาษณ์ของทีมตรวจจริง"* — **ห้ามลบเด็ดขาด** เพราะการ์ดชุดนี้เป็นบุคคลสมมติทั้งหมด ถ้าตัดออกจะกลายเป็นการกล่าวอ้างว่ามีทีมผู้เชี่ยวชาญจริงตามชื่อเหล่านี้ ตรวจแล้วว่ายังอยู่ครบ

**ตรวจแล้ว:** การ์ดขึ้นครบ 4 ใบ · ป้ายหมวดถนัดขึ้นถูกทุกใบ · คำพูดตรงกับต้นฉบับของ Boss ทุกคำ · แท็กครบ · หมายเหตุยังอยู่ · `typeof showPage` = function (สคริปต์ไม่ตาย) · ไม่มี error ใหม่ใน console

**เรื่องการเผยแพร่:** ตอนจะเผยแพร่ทับ Artifact เจอ conflict จาก session คู่ขนาน ตรวจแล้วพบว่า **เวอร์ชัน live ล่าสุดมีการแก้ของผมครบอยู่แล้ว** (อีก session รีบิลด์จาก `build-mockup.py` ตัวเดียวกันที่ผมแก้ไปแล้ว จึงพางานผมขึ้นไปด้วย) — **จึงไม่ได้เผยแพร่ซ้ำ ไม่ใช่ว่างานไม่ขึ้น** ยืนยันด้วยการค้นหาข้อความใหม่ในไฟล์ live แล้วเจอครบทุกจุด

### ✅ งานต่อเนื่อง — แถว Hall of Fame (เสร็จแล้ว)

Boss สั่งต่ออีก 3 รอบระหว่างงานเดียวกัน:

1. **"ปรับขนาดให้ใหญ่ขึ้น และเลื่อนซ้ายไปเรื่อย ๆ จัด UI ให้สวยหน่อย"**
   - เปลี่ยนแถว Hall of Fame จาก **grid 5 คอลัมน์ตายตัว → แถวเลื่อนซ้ายอัตโนมัติ (marquee)** วนไม่จบ
   - **ขยายการ์ด** จาก ~210px เป็น **264px** · โลโก้ 68→**84px** · ตัวเลขไตรมาส 22→**28px** · ชื่อโบรก 15.5→**17.5px**
   - จัด UI เพิ่ม: ใส่ **mask ไล่จางที่ขอบซ้าย-ขวา** ให้การ์ดค่อย ๆ เลือนหายแทนที่จะโดนตัดขาด
2. **"ปรับตัว 3 ดาวให้ดูเด่นหน่อย"** — ครอบแถวดาวด้วย **ป้ายกรอบทองโปร่ง + เรืองแดง** (`.aw-hxs`) และขยายดาว 16→**22px** แยกดาวออกจากตัวเลขไตรมาสให้อ่านง่ายขึ้น

**เรื่องที่ยึดตามกฎโปรเจ็คโดยไม่ต้องรอสั่ง:** เนื้อหาที่**ขยับเองต้องหยุดได้** (ข้อกำหนดการเข้าถึงที่โปรเจ็คนี้ล็อกไว้แล้วตั้งแต่ทำแถบเตือนภัยหน้าแรก) จึงใส่ **ปุ่มหยุด/เล่นมุมขวาบน** พร้อม `aria-pressed` · **หยุดเองเมื่อเอาเมาส์ชี้** · และ **ปิดอนิเมชันให้อัตโนมัติเมื่อผู้ใช้ตั้ง `prefers-reduced-motion`**

**รายละเอียดเทคนิคที่ต้องจำ:** ใช้ `margin-right` แทน `gap` บน track เพราะต้องให้ทุกใบกว้างเท่ากันเป๊ะ `translateX(-50%)` ถึงจะต่อเนียนไม่มีรอยสะดุด — ตรวจแล้วว่า `halfTrack === oneSetWidth === 1410px` พอดี · การ์ดชุดที่สองเป็นภาพซ้ำ ใส่ `aria-hidden="true"` + `tabindex="-1"` กันโปรแกรมอ่านหน้าจออ่านซ้ำและกัน tab หลงเข้าไป
