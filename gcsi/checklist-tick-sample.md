# GCSI — ตัวอย่างรูปแบบเช็กลิสต์ (ทดสอบ 10 ข้อแรก)

ทดสอบรูปแบบก่อนลงมือทำเต็มชุด — เสา P01, ข้อ P01-001 ถึง P01-010

| ติ๊ก | รหัสข้อ | หัวข้อตรวจ |
|:---:|---|---|
| ○ | P01-001 | เว็บไซต์ระบุเลขใบอนุญาตหรือไม่ |
| ○ | P01-002 | ระบุชื่อหน่วยงานกำกับที่ออกใบอนุญาตชัดเจนหรือไม่ |
| ○ | P01-003 | ระบุชื่อนิติบุคคลที่ถือใบอนุญาตหรือไม่ |
| ○ | P01-004 | เลขใบอนุญาตค้นเจอในทะเบียนสาธารณะของหน่วยงานหรือไม่ |
| ○ | P01-005 | ชื่อในทะเบียนตรงกับชื่อนิติบุคคลที่เว็บอ้างหรือไม่ |
| ○ | P01-006 | สถานะในทะเบียนเป็น "ใช้งานอยู่" หรือไม่ |
| ○ | P01-007 | วันที่ใบอนุญาตเริ่มมีผลตรงกับที่โบรกโฆษณาหรือไม่ |
| ○ | P01-008 | ทะเบียนแสดงการระงับหรือข้อจำกัดที่ยังมีผลหรือไม่ |
| ○ | P01-009 | ที่อยู่ในทะเบียนตรงกับที่อยู่บนเว็บหรือไม่ |
| ○ | P01-010 | โดเมนที่ใช้จริงถูกแจ้งไว้ในทะเบียนหรือไม่ |

---

**คำถามก่อนทำเต็มชุด:**
1. ทำครบกี่ข้อ — 1,000 ข้อที่ติด ● หรือครบ 3,000 ข้อ หรือทั้งสองชุด
2. รูปแบบพอดีไหม — แค่นี้ หรืออยากได้ 3 ช่องติ๊ก (ผ่าน / ไม่ผ่าน / ยังไม่ได้ตรวจ) แทนวงกลมเดียว
3. ใช้แทนเอกสารเดิม (ฉบับเต็ม 7 ส่วน) หรือทำเป็นเอกสารเสริมคู่กัน
