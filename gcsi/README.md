## 1. หลักการที่ต่างจาก Audit ทั่วไป — อ่านก่อนใช้เกณฑ์นี้

GCSI **ไม่ใช่** การตรวจแบบ ISO/มาตรฐานองค์กร ที่เข้าไปขอเอกสารภายใน สัมภาษณ์ผู้บริหาร หรือเข้าไซต์

**GCSI คือการตรวจในฐานะเทรดเดอร์ทั่วไปคนหนึ่ง**

| | ISO / Audit ทั่วไป | **GCSI** |
|---|---|---|
| ผู้ถูกตรวจรู้ตัว | รู้ล่วงหน้า นัดหมาย | **ไม่รู้ตัวเลย** |
| แหล่งหลักฐาน | เอกสารภายในที่องค์กรส่งให้ | **สิ่งที่โบรกเกอร์แสดงต่อสาธารณะและต่อลูกค้าอยู่แล้ว** |
| สถานะผู้ตรวจ | ผู้ตรวจสอบที่ได้รับเชิญ | **ลูกค้ารายย่อยที่เปิดบัญชีด้วยเงินสถาบัน** |
| สิ่งที่ขอได้ | ขอเอกสารเพิ่มได้ | **ขอไม่ได้ — ได้แค่สิ่งที่ลูกค้าทั่วไปได้** |
| การแก้ปัญหา | แจ้ง finding ให้แก้ | **แก้ผ่านช่องทางลูกค้าปกติ แล้วให้คะแนนจากผลจริง** |

### 1.1 กฎเหล็กของทุกข้อในชุดนี้

> **ทุกข้อต้องตรวจได้โดยคนที่ไม่มีสถานะพิเศษใด ๆ**

ข้อใดที่ต้องอาศัยสิ่งต่อไปนี้ **ห้ามอยู่ในชุดนี้**
- ความร่วมมือของโบรกเกอร์ · การขอเอกสารภายใน · สิทธิ์เข้าถึงระบบหลังบ้าน
- การสัมภาษณ์พนักงานในฐานะผู้ตรวจ · การเข้าสำนักงาน · การขอ audit report ที่ไม่เปิดสาธารณะ
- การเปิดเผยตัวว่าเป็นผู้ตรวจ ไม่ว่ากรณีใด

## 3. กฎการให้ดาว — ต้องผ่านครบทุกข้อ ไม่มีคะแนนถัวเฉลี่ย

> **GCSI 1 ดาว = ผ่านครบทั้ง 3,000 / 3,000 ข้อ ไม่มีข้อยกเว้นแม้แต่ข้อเดียว**
> ไม่มีสูตรถ่วงน้ำหนัก ไม่มีเกณฑ์เปอร์เซ็นต์ ไม่มีการหักคะแนนแล้วยังผ่านได้ — **ไม่ผ่าน 1 ข้อ = ไม่ได้ดาว**

### 3.1 สถานะ "ยังไม่ได้ตรวจ" ต้องเคลียร์ให้หมดก่อน

โบรกจะมีสิทธิ์ได้ดาวก็ต่อเมื่อ**ตรวจครบทั้ง 3,000 ข้อจริง** — ไม่มีข้อไหนค้างสถานะ "ยังไม่ได้ตรวจ" เลย
ตราบใดที่ยังมีข้อค้างตรวจอยู่ แม้ข้อที่ตรวจแล้วทั้งหมดจะผ่านหมด ก็ยังไม่มีสิทธิ์ได้ดาว — ต้องแสดงสถานะ **"อยู่ระหว่างตรวจ"** จนกว่าจะครบ

### 3.2 รอบตรวจ — ทุกไตรมาส ตรวจใหม่ทั้งหมด

- ตรวจโบรกแต่ละราย**ใหม่ทั้ง 3,000 ข้อทุกไตรมาส** หลักฐานของไตรมาสก่อนหมดอายุอัตโนมัติเมื่อขึ้นไตรมาสใหม่ ไม่ใช้หลักฐานเก่าข้ามรอบ
- **ดาวของไตรมาสก่อนหน้ายังคงแสดงต่อเนื่อง** จนกว่าผลไตรมาสใหม่จะออกและได้รับการรับรอง — ไม่มีช่วง "ไม่มีดาว" คั่นระหว่างรอผล
- เมื่อผลไตรมาสใหม่ออก ดาวเปลี่ยนตามผลจริงทันที (คงดาว / ถอนดาว / เพิ่งได้ดาวใหม่)

### 3.3 สถานะที่แสดงต่อสาธารณะ

| สถานะ | เงื่อนไข |
|---|---|
| **★ ได้ดาว** | ผ่านครบ 3,000/3,000 ข้อ ในไตรมาสล่าสุดที่ตรวจรับรองแล้ว |
| **อยู่ระหว่างตรวจ** | ยังตรวจไม่ครบ 3,000 ข้อในไตรมาสปัจจุบัน (ยังแสดงดาวไตรมาสก่อนถ้ามี) |
| **ไม่ได้ดาว** | ตรวจครบแล้วแต่มีอย่างน้อย 1 ข้อไม่ผ่าน |

## 5. รูปแบบของทุกข้อในชุดนี้

ทุกข้อเขียนครบ 6 ส่วนเสมอ

```
#### P0X-NNN · ชื่อข้อ
- ตรวจอะไร : สิ่งที่ต้องดู อย่างละเอียด ระบุจุดที่ต้องเปิดดู
- หลักฐาน  : สิ่งที่ต้องเก็บเป็นหลักฐาน (ต้องย้อนกลับได้)
- ผ่าน     : เงื่อนไขที่ถือว่าผ่าน
- ไม่ผ่าน  : เงื่อนไขที่ถือว่าไม่ผ่าน
- ตัวอย่าง : กรณีจริงที่เห็นภาพ (ใช้ชื่อโบรกสมมติเท่านั้น)
- น้ำหนัก / เว็บ / วิธี
```

### 5.1 สถานะที่สามของทุกข้อ (นิยามกลาง ไม่ต้องเขียนซ้ำรายข้อ)

> **"ยังไม่ได้ตรวจ"** = เข้าถึงแหล่งหลักฐานไม่ได้ · ยังไม่ถึงรอบทดสอบ · หรือหลักฐานที่ได้ไม่พอสรุป
> **ห้าม** ตีความว่าเป็น "ไม่ผ่าน" และ **ห้าม** ให้ 0 **ห้าม** เว้นว่าง — ต้องแสดงคำว่า *ยังไม่ได้ตรวจ* บนเว็บ

### 5.2 ตัวเลขเกณฑ์ที่ยังไม่ประกาศ

ข้อที่ต้องใช้ตัวเลขตัดสิน จะเขียนไว้เป็น **`[เกณฑ์เสนอ: …]`**
= ตัวเลขที่ Doing เสนอ **ยังไม่มีผลจนกว่า Boss อนุมัติ**

> ⛔ **ต้องประกาศตัวเลขทั้งหมดก่อนตรวจโบรกรายแรก — ห้ามตั้งหลังเห็นผล**

### 5.3 สัญลักษณ์

| สัญลักษณ์ | ความหมาย |
|---|---|
| **●** | ข้อที่**เปิดเผยบนเว็บ** (นับรวม 1,000 ข้อ) |
| *(ว่าง)* | ข้อหลังบ้าน ไม่แสดงบนเว็บ |
| **G1**–**G6** | ข้อที่ผูกกับด่านบังคับ |

### 5.4 ชื่อโบรกสมมติที่ใช้ในตัวอย่างทั้งชุด

`Broker A` · `Broker B` · `Broker C` — **ห้ามใช้ชื่อโบรกเกอร์จริงคู่กับผลสมมติเด็ดขาด**
