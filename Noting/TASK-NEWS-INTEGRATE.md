## 2. งานที่ขอให้ทำ

เอาข่าวจริง 5 เรื่องนี้ไปแทนที่ **"บทความเด่น 5 บท"** ที่เป็นข้อมูลสมมติในหน้า Home/News ของต้นแบบ (`design/Main.dc.html` + `design/build-mockup.py` → build ออกมาเป็น `redstartrust-homepage-mockup.html`)

ใช้ **ฉบับภาษาไทย (`th.md`)** เป็นเนื้อหาหลักก่อน เพราะตามที่บันทึกไว้ใน `STATE.md` ปุ่มสลับภาษายังไม่ได้ต่อการแปลเนื้อหาจริง (สลับได้แค่สถานะปุ่ม) — ฉบับ `en.md` เก็บไว้เป็นข้อมูลสำรองสำหรับตอนที่ระบบสองภาษาทำงานจริง ยังไม่ต้องใช้ตอนนี้

## 3. จุดที่ต้องระวัง — ⚠️ ข้อจำกัดสำคัญของไฟล์ที่เผยแพร่

จากที่บันทึกไว้ใน `STATE.md` ข้อ 5 (ส่วนบทความเด่น): **"ไม่ใช้ภาพถ่ายและไม่ใช้โลโก้โบรกเกอร์ เพราะหน้าที่เผยแพร่โหลดไฟล์ภายนอกไม่ได้"** — Artifact เป็นไฟล์เดียวจบในตัว โหลดรูปจากไฟล์แยกไม่ได้

รูปปก 5 ภาพที่ Going วาดมาเป็นไฟล์ `.webp` แยก **ไม่สามารถอ้างอิงเป็น path ตรง ๆ ได้** ต้องเลือกวิธีใดวิธีหนึ่ง:

- **(แนะนำ)** แปลงรูป 5 ภาพเป็น base64 แล้วฝังเป็น `data:image/webp;base64,...` ในสคริปต์ (ไฟล์เล็กมาก 3–15 KB/ภาพ รวมกันไม่หนักเว็บ)
- หรือถ้าอยากให้สไตล์ตรงกับปกบทความอีก 14 แบบที่มีอยู่แล้ว (วาดเป็นเวกเตอร์ในไฟล์ทั้งหมดตามที่บันทึกไว้) — **วาดใหม่เป็นเวกเตอร์ในสไตล์เดียวกัน** โดยดูคอนเซปต์จาก `cover_alt`/`cover_caption` ในแต่ละไฟล์ `th.md` ก็ได้ อันนี้ Noting ตัดสินใจเลือกแนวทางที่เข้ากับระบบเดิมที่สุด

## 4. ข้อมูลที่ต้อง map เข้าการ์ดข่าว (ตามโครงสร้างการ์ดที่มีอยู่แล้ว)

จาก frontmatter ของแต่ละ `th.md`:
- `title` → หัวข้อการ์ด
- `excerpt` → คำโปรยใต้หัวข้อ
- `category` / `subcat` → ใช้กับชิปกรองหมวดที่มีอยู่แล้ว (ตรวจดูว่าหมวดเดิมในต้นแบบตรงกับ `stock-market / investment / regulator / business` ไหม ถ้าไม่มีหมวดเหล่านี้ในระบบกรองเดิม ให้เพิ่มหรือถามผมก่อนถ้าไม่แน่ใจว่าจะจัดยังไง)
- `date` + `time` → วันที่/เวลาเผยแพร่
- `cover_alt` / `cover_caption` → ข้อความกำกับรูป (alt text / caption ใต้ภาพ)
- `verdict` → ใช้เป็นคำโปรยเสริมได้ถ้าต้องการ (ไม่บังคับ)
- เนื้อหาเต็มในบอดี้ของไฟล์ — ใช้ตอนกดเข้าไปอ่านบทความเต็ม ถ้าระบบยังไม่มีหน้ารายบทความแยก ให้ใส่ไว้เป็นข้อมูลพร้อมใช้ (data) ก่อน ยังไม่ต้องสร้างหน้าใหม่ถ้ายังไม่มีเวลา — ถามผมถ้าจะขยายเป็นหน้ารายบทความ

## 5. สิ่งที่ไม่ต้องทำตอนนี้

- ไม่ต้องแปลเนื้อหาให้ปุ่มภาษาใช้งานจริง (นอกขอบเขตงานนี้)
- ไม่ต้องลบข้อมูลสมมติเดิมทั้งหมดถ้ายังไม่มีข่าวจริงครบ 5 บทพอดี — จะผสมข่าวจริง 5 เรื่องนี้กับของเดิมที่เหลือก็ได้ แต่ต้องแยกให้ชัดว่าอันไหนข่าวจริง
