# logos/ — ช่องใส่โลโก้โบรกเกอร์

วางไฟล์โลโก้ในโฟลเดอร์นี้ แล้วต้นแบบจะสลับจากตัวยึด (ตัวย่อบนพื้นสี) เป็นโลโก้จริง **อัตโนมัติ ไม่ต้องแก้โค้ด**

## ชื่อไฟล์

ต้องตรงกับ slug ของโบรกเกอร์เป๊ะ ๆ:

```
logos/exness.svg
logos/ic-markets.svg
logos/xm.svg
logos/pepperstone.svg
logos/fp-markets.svg
logos/eightcap.svg
logos/tickmill.svg
logos/axi.svg
logos/hfm.svg
```

หน้า Minimal Luxury ใช้เพิ่มอีก 3 ราย: `ig.svg` · `oanda.svg` · `equiti.svg`

## สเปกไฟล์

| หัวข้อ | ค่า |
|---|---|
| รูปแบบ | **SVG** (ดีที่สุด) · ถ้าไม่มีใช้ PNG พื้นหลังโปร่ง ความละเอียด 2 เท่า อย่างน้อย 128×128 px |
| สัดส่วน | **จัตุรัส** — ถ้าโลโก้เป็นแนวนอน ให้วางกลางกรอบจัตุรัสแล้วเว้นขอบบน-ล่าง |
| ระยะขอบ | เว้นพื้นที่ว่างรอบโลโก้อย่างน้อย 10% ของด้าน ไม่ให้ชิดขอบ |
| พื้นหลัง | โปร่งใส — ระบบจะวางบนพื้นขาวให้เอง |
| ขนาดไฟล์ | ไม่เกิน 40 KB ต่อไฟล์ |

## ที่ยังไม่ได้ทำ

- **โลโก้เวอร์ชันโหมดมืด** — โลโก้ที่เป็นสีเข้มล้วนจะจมหายในโหมดมืด ตอนนี้ระบบวางโลโก้บนพื้นขาวเสมอเพื่อกันปัญหานี้ไปก่อน ถ้าต้องการให้กลืนกับพื้นมืด ต้องเพิ่มไฟล์ `<slug>-dark.svg` และผมต้องแก้สคริปต์เพิ่ม
- **บนหน้าที่เผยแพร่เป็นลิงก์ (Artifact)** โฟลเดอร์นี้ใช้ไม่ได้ ต้องฝังไฟล์เข้าไปในหน้าโดยตรง — ส่งไฟล์มาให้ผม แล้วผมฝังให้

## ข้อควรระวังเรื่องสิทธิ์ — อ่านก่อนหาไฟล์

โลโก้โบรกเกอร์เป็น **เครื่องหมายการค้า** ของบริษัทนั้น การนำมาแสดงบนเว็บรีวิว/จัดอันดับโดยทั่วไปทำได้ในฐานะการอ้างถึงเพื่อระบุตัวผู้ประกอบการ แต่ต้องระวัง 3 ข้อ:

1. **เอาไฟล์จากแหล่งทางการเท่านั้น** — หน้า Press Kit / Brand Assets / Media Kit ของโบรกเกอร์เอง หรือชุดสื่อที่ได้รับจากฝ่าย partner **ห้ามแคปหน้าจอมาไล่วาดเอง** เพราะจะได้ของที่ผิดรูปและผิดเงื่อนไขการใช้งานของเจ้าของ
2. **ทำตามคู่มือแบรนด์ของเขา** — หลายเจ้าระบุระยะขอบขั้นต่ำ สีที่ห้ามเปลี่ยน และห้ามบิดสัดส่วน
3. **ห้ามใช้ในลักษณะที่ทำให้เข้าใจว่าโบรกเกอร์รับรองเรา** — เราเป็นผู้ตรวจอิสระ การวางโลโก้ต้องอยู่ในบริบท "รายชื่อผู้ถูกตรวจ" ไม่ใช่ "พันธมิตรของเรา" ซึ่งขัดกับเสาความเป็นอิสระใน `CORE-PILLAR.md`

ถ้าโบรกเกอร์รายใดไม่อนุญาต ระบบจะแสดงตัวยึดตัวย่อไปตามปกติ หน้าเว็บไม่พัง

### ข้อจำกัดที่ต้องรู้

1. **ไฟล์ส่วนใหญ่เป็นไอคอนประจำเว็บ (favicon) ไม่ใช่โลโก้เต็ม** — เป็นเครื่องหมายย่อของแบรนด์ ไม่มีชื่อบริษัทประกอบ
2. **บางรายได้แค่ 32×32 px** (IC Markets, XM, Pepperstone, HFM, Axi) — ผมตั้งค่าไม่ให้ระบบขยายภาพเกินขนาดจริง จึงคมเสมอ แต่จะดูเล็กกว่าช่องในการ์ดใหญ่ **ถ้าอยากได้เต็มพื้นที่ ต้องหาไฟล์ความละเอียดสูงจากหน้า Brand Assets ของเขามาแทน**
3. **Tickmill เปลี่ยนอัตลักษณ์ปี 2568** — ไฟล์ที่ได้มาจากเว็บเขาโดยตรงจึงเป็นเวอร์ชันปัจจุบัน แต่ควรตรวจซ้ำก่อนใช้จริง
4. ผมไม่ได้ตรวจเงื่อนไขการใช้งานของแต่ละเจ้าเป็นรายข้อ — **ยังเป็นเรื่องที่ต้องให้ผู้รับผิดชอบด้านกฎหมายดูก่อนเผยแพร่จริง**
