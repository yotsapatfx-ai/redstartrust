# logos/ — ช่องใส่โลโก้โบรกเกอร์

วางไฟล์โลโก้ในโฟลเดอร์นี้ แล้วต้นแบบจะสลับจากตัวยึด (ตัวย่อบนพื้นสี) เป็นโลโก้จริง **อัตโนมัติ ไม่ต้องแก้โค้ด**

## ชื่อไฟล์

ต้องตรงกับ slug ของโบรกเกอร์เป๊ะ ๆ:

```
logos/exness.svg
logos/ic-markets.svg
logos/xm.svg
logos/pepperstone.svg
logos/fp-markets.svg
logos/eightcap.svg
logos/tickmill.svg
logos/axi.svg
logos/hfm.svg
```

หน้า Minimal Luxury ใช้เพิ่มอีก 3 ราย: `ig.svg` · `oanda.svg` · `equiti.svg`

## สเปกไฟล์

| หัวข้อ | ค่า |
|---|---|
| รูปแบบ | **SVG** (ดีที่สุด) · ถ้าไม่มีใช้ PNG พื้นหลังโปร่ง ความละเอียด 2 เท่า อย่างน้อย 128×128 px |
| สัดส่วน | **จัตุรัส** — ถ้าโลโก้เป็นแนวนอน ให้วางกลางกรอบจัตุรัสแล้วเว้นขอบบน-ล่าง |
| ระยะขอบ | เว้นพื้นที่ว่างรอบโลโก้อย่างน้อย 10% ของด้าน ไม่ให้ชิดขอบ |
| พื้นหลัง | โปร่งใส — ระบบจะวางบนพื้นขาวให้เอง |
| ขนาดไฟล์ | ไม่เกิน 40 KB ต่อไฟล์ |

## ที่ยังไม่ได้ทำ

- **โลโก้เวอร์ชันโหมดมืด** — โลโก้ที่เป็นสีเข้มล้วนจะจมหายในโหมดมืด ตอนนี้ระบบวางโลโก้บนพื้นขาวเสมอเพื่อกันปัญหานี้ไปก่อน ถ้าต้องการให้กลืนกับพื้นมืด ต้องเพิ่มไฟล์ `<slug>-dark.svg` และผมต้องแก้สคริปต์เพิ่ม
- **บนหน้าที่เผยแพร่เป็นลิงก์ (Artifact)** โฟลเดอร์นี้ใช้ไม่ได้ ต้องฝังไฟล์เข้าไปในหน้าโดยตรง — ส่งไฟล์มาให้ผม แล้วผมฝังให้

## ข้อควรระวังเรื่องสิทธิ์ — อ่านก่อนหาไฟล์

โลโก้โบรกเกอร์เป็น **เครื่องหมายการค้า** ของบริษัทนั้น การนำมาแสดงบนเว็บรีวิว/จัดอันดับโดยทั่วไปทำได้ในฐานะการอ้างถึงเพื่อระบุตัวผู้ประกอบการ แต่ต้องระวัง 3 ข้อ:

1. **เอาไฟล์จากแหล่งทางการเท่านั้น** — หน้า Press Kit / Brand Assets / Media Kit ของโบรกเกอร์เอง หรือชุดสื่อที่ได้รับจากฝ่าย partner **ห้ามแคปหน้าจอมาไล่วาดเอง** เพราะจะได้ของที่ผิดรูปและผิดเงื่อนไขการใช้งานของเจ้าของ
2. **ทำตามคู่มือแบรนด์ของเขา** — หลายเจ้าระบุระยะขอบขั้นต่ำ สีที่ห้ามเปลี่ยน และห้ามบิดสัดส่วน
3. **ห้ามใช้ในลักษณะที่ทำให้เข้าใจว่าโบรกเกอร์รับรองเรา** — เราเป็นผู้ตรวจอิสระ การวางโลโก้ต้องอยู่ในบริบท "รายชื่อผู้ถูกตรวจ" ไม่ใช่ "พันธมิตรของเรา" ซึ่งขัดกับเสาความเป็นอิสระใน `CORE-PILLAR.md`

ถ้าโบรกเกอร์รายใดไม่อนุญาต ระบบจะแสดงตัวยึดตัวย่อไปตามปกติ หน้าเว็บไม่พัง

## สถานะไฟล์ปัจจุบัน (30 ส.ค. 2569)

**มีโลโก้แล้ว 57 จาก 61 ราย** — รอบ 26 ส.ค. ได้ 11 ราย · รอบ 30 ส.ค. เพิ่มอีก 46 ราย

Boss อนุมัติให้ดำเนินการ ผมจึงดึง **ไอคอนแบรนด์จากโดเมนทางการของโบรกเกอร์เอง**
โดยอ่านแท็ก `<link rel="icon">` / `apple-touch-icon` จากหน้าแรกของเขา แล้วโหลดไฟล์ที่ประกาศไว้ใหญ่ที่สุด
**ไม่ได้ติดต่อฝ่าย partner หรือ affiliate ของรายใดทั้งสิ้น**

รายที่หน้าแรกตอบ 403 (Cloudflare) ใช้สองวิธีสำรอง
1. ยิงตรงไปที่พาธไอคอนมาตรฐานบนโดเมนเดียวกัน (`/apple-touch-icon.png`, `/favicon.ico` ฯลฯ)
2. เปิดหน้าเว็บผ่านเบราว์เซอร์จริงแล้วอ่าน URL ไอคอนจาก DOM (บางรายไอคอนอยู่บน CDN ของเขาเอง)

### การจัดไฟล์ก่อนฝัง

| ขั้น | ทำอะไร |
|---|---|
| 1 | `.ico` ที่มีหลายเฟรม เอาเฟรมใหญ่ที่สุด |
| 2 | `.webp` / `.jpg` แปลงเป็น PNG |
| 3 | ตัดขอบโปร่งใสที่ติดมากับไฟล์ออก เว้นไว้ 2% — ได้พื้นที่คืนโดยไม่ต้องขยายภาพ |
| 4 | ด้านยาวสุดไม่เกิน 160px ไฟล์ละไม่เกิน 20KB |
| 5 | `.svg` ปล่อยไว้อย่างเดิม |

**ไม่ขยายภาพเล็กให้ใหญ่ขึ้น** เพราะจะเบลอ `mountLogo()` แสดงตามขนาดจริงเสมอ แล้วจัดกึ่งกลางกรอบให้

### ครบ 61/61 แล้ว (31 ส.ค. 2569)

สี่รายสุดท้ายที่รอบแรกไม่ผ่าน ได้มาด้วยวิธีต่างกัน — **บันทึกที่มาไว้ให้ตรวจย้อนได้**

| slug | ที่มา |
|---|---|
| `blackbull-markets` | `blackbull.com/favicon.ico` โดยตรง — ต้องใส่ header แบบเบราว์เซอร์เต็มชุด (sec-ch-ua, sec-fetch-*) ถึงผ่าน |
| `degiro` | พร็อกซีภาพที่ไปดึง `www.degiro.com/favicon.ico` ให้จากฝั่งเซิร์ฟเวอร์ ได้ 160px |
| `bitstamp` | บริการไอคอนที่มิเรอร์จาก `www.bitstamp.net` — เว็บเขาใช้ Imperva บล็อกทุกทางตรง |
| `bybit` | บริการไอคอนที่มิเรอร์จาก `www.bybit.com` — บล็อกทั้ง DNS และ WAF |

**สองรายล่างเป็นไฟล์ที่มิเรอร์มา ไม่ได้ดึงจากโดเมนเจ้าของโดยตรง** ต่างจากอีก 59 ราย
ตรวจภาพทั้งสี่ด้วยตาแล้วว่าตรงแบรนด์ ไม่ใช่ไอคอนกลาง ๆ

### ข้อจำกัดที่ต้องรู้

1. **ไฟล์เกือบทั้งหมดเป็นไอคอนประจำเว็บ (favicon) ไม่ใช่โลโก้เต็ม** — เป็นเครื่องหมายย่อ ไม่มีชื่อบริษัทประกอบ
2. **บางรายได้ไฟล์เล็กมาก** — FXTM 16×16 · Stage 5 Trading 16×16 · Hargreaves Lansdown 32×20 ·
   Crypto.com 28×32 · IC Markets / XM / Pepperstone / HFM / Vanguard / Gate.io 32px
   จะดูเล็กกว่าช่องในการ์ด ถ้าอยากได้เต็มพื้นที่ต้องหาไฟล์ความละเอียดสูงจากหน้า Brand Assets มาแทน
3. **โลโก้แนวนอน** เช่น Tradovate จะแสดงกว้าง-เตี้ยกลางกรอบ ไม่ได้บิดสัดส่วน
4. **ตรวจภาพทีละใบแล้ว** ด้วยคอนแทกต์ชีต ว่าตรงแบรนด์ ไม่ใช่ไอคอนกลาง ๆ และไฟล์ไม่เสีย
   — ระหว่างทางเจอไฟล์เสีย 1 ใบ (Bybit) จับได้แล้วลบทิ้ง จึงไม่มีของเสียหลุดเข้าไป
5. ผมไม่ได้ตรวจเงื่อนไขการใช้งานของแต่ละเจ้าเป็นรายข้อ —
   **ยังเป็นเรื่องที่ต้องให้ผู้รับผิดชอบด้านกฎหมายดูก่อนเผยแพร่จริง**
